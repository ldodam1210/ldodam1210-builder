# 헤어띵크 — 랜딩 페이지

커트 레시피를 3D 로 설계하세요. 헤어 컷트 강사용 3D 패널 설계 도구의 소개 페이지입니다.

## 주소
- 사이트: https://ldodam1210-builder.vercel.app
- GitHub 저장소: https://github.com/ldodam1210/ldodam1210-builder
- Supabase 대시보드: https://supabase.com/dashboard/project/cknjgjdqafbwsqcxdodq

## Supabase
연결만 해 둔 상태입니다. 다음 주에 신청 저장 같은 기능을 붙일 때 씁니다.

## 다시 고칠 때
Claude 나 Codex 앱에서 이 폴더를 열고 고쳐 달라고 말한 다음:

```bash
git add -A && git commit -m "수정" && git push
vercel --prod --yes
```

(GitHub 자동 배포가 아직 연결되지 않아서, 사이트는 `vercel --prod --yes` 로 직접 다시 올립니다.)

## 도메인
내 도메인을 붙이고 싶으면 vercel.com 의 이 프로젝트 → Settings → Domains 에서 합니다.
